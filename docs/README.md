# Vestopia Documentation

Vestopia is a simulated investing game for beginners. Players build a pixel-art village from a portfolio of simulated stocks on **Monad Testnet**. All prices and assets are simulated for education. They are not real stocks and this is not investment advice.

These documents use plain language so that judges, partners and non-technical teammates can read them.

## 30-second summary

- **Problem:** many young people want to invest, but they fear losing money and do not understand risks such as debt and falling prices.
- **Solution:** investing becomes a village-building game. Sectors become districts, stocks become lots, dividends become harvests, and loans become weather (sunny, cloudy, stormy).
- **Technology:** all assets and transactions live in smart contracts on Monad Testnet. Players can sign in with email, Google or a wallet.
- **Status (10 Oct 2026):** contracts are deployed, the game is connected to the chain, and Privy login is built. Monad Metropolis hackathon submission deadline: **13 October 2026**.

## Honesty notes

- Stock prices in the game are **not real market prices**. An admin sets them by hand through a simulated oracle.
- Coins and stock tokens have no monetary value.
- The contracts are unaudited and testnet only.
