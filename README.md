# Vestopia

Vestopia is a simulated investing game for beginners. Players build a pixel-art village from a portfolio of simulated stocks.

## Repository layout

- `frontend` Next.js, Phaser and Zustand app. See `frontend/README.md`
- `contracts` Foundry smart contracts (not started)
- `docs` product specs and design notes

All prices and assets are simulated for educational purposes. They are not real stocks and this is not investment advice.
